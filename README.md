# Lochni Mallik | Personal Portfolio & Blog

## About the Project
This is my personal portfolio and blog website created as part of my Web Development Day 03 task. It represents my introduction, interests, creativity, and learning journey as an aspiring web developer.

## Pages Included
1. **Home:** Introduces me and highlights my interests.
2. **About:** Shares information about me, my background, and my skills.
3. **Blog:** Provides a space to share my thoughts, ideas, and experiences.

## Technologies Used
- HTML5
- CSS3

## Features
- Simple and attractive user interface.
- Navigation bar to switch between pages.
- Personal introduction section.
- Separate Home, About, and Blog pages.
- Creative cards and content sections.
- External CSS styling.

## Project Structure
- `index.html` – Home page
- `about.html` – About page
- `blog.html` – Blog page
- `styles.css` – Website styling

## How to Run
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Explore the different pages using the navigation bar.

## Learning Outcomes
- Understanding HTML structure.
- Applying CSS styles to webpages.
- Creating multiple webpages.
- Linking webpages using navigation links.
- Connecting an external CSS stylesheet.
